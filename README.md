# The Clinical Commons v1.2

Bilingual (English / Arabic) release of *The Clinical Commons*: a proposed hospital governance model in which
multidisciplinary clinical teams steward care, an accountable board manages resources, and community
representatives oversee mission and equity.

**DOI (all versions, resolves to the latest):** [10.5281/zenodo.23604174](https://doi.org/10.5281/zenodo.23604174)
**DOI of this version (1.2):** [10.5281/zenodo.23606022](https://doi.org/10.5281/zenodo.23606022) · Zenodo record: https://zenodo.org/records/23606022
Part of the [BPR community on Zenodo](https://zenodo.org/communities/bpr-doctors/).

## Video

`the-clinical-commons.mp4`: an 88-second vertical summary in Arabic and English (1080×1920, made with Remotion),
also at https://elfadil.brainsait.de/media/the-clinical-commons.mp4. Poster: `the-clinical-commons-poster.jpg`.

## Source and build

The video is built from source in this repository: `video/` holds the Remotion project, the
deterministic ambient-soundtrack generator, and the audio-mixing script. The
`Build and publish` workflow renders the video and poster on every change and publishes
them here, so these files are reproducible rather than uploaded by hand.
